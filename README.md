# Чубрик

Яркий 3D-платформер про прикольного чубрика (Unity 6, всё строится из кода — `Assets/Scripts/Core/Boot.cs`).

**Мир 1 — Лобби**: безопасный остров без врагов. Фонтан, магазин примочек, премиум-киоск, гардероб,
порталы в будущие миры, полоса прыжков с башней, грибы-батуты, летающие острова, ящики и мишени,
кактус-тренер, музыкальная дорожка, монеты и 10 спрятанных жетонов.

- **Гардероб**: 31 отдел × 8 вещей из диздока + 32 эксклюзива из 8 премиум-наборов (280 вещей).
- **Магазин примочек**: лутбоксы, навигатор монет, набор 100 монет, жетоны, жизни до 6.
- **Премиум-наборы**: 8 штук, 1 000 – 2 990 ₸ (оплата пока не подключена). Промокод разработчика открывает все.
- Управление: WASD, пробел (двойной прыжок, полёт с крыльями), F — удар, Q — эмоция, E — войти; на телефоне — джойстик и кнопки.

Скрипты: `build_and_test.sh DIR` (сборка Mac + автотест со скриншотами), `release.sh ВЕРСИЯ` (APK в GitHub Releases),
`publish_web.sh` (браузерная версия на GitHub Pages после `BuildScript.BuildWebGL`). `cool.sh` ждёт, если Mac перегрелся.
